# Clima para Rinconada Stereo — investigación (23 de septiembre de 2026)

## Recomendación

Para la primera versión estática, usar el widget gratuito de **WeatherWidget.io** si las tres ubicaciones se pueden seleccionar correctamente en su configurador. Es gratuito también para sitios comerciales, no pide registro ni clave, es adaptable y permite cambiar colores, tipografía, rótulos y días de pronóstico. La web pública cumple el caso de uso permitido. No se debe quitar el enlace que trae hacia Forecast7 ni alterar el código para impedirlo. Admite hasta ocho widgets por página y 35 ubicaciones por sitio. [Producto y preguntas frecuentes](https://weatherwidget.io/); [términos](https://weatherwidget.io/terms/).

Si el configurador no localiza bien La Pacha o La Rinconada, probar el **widget gratuito de meteoblue** con la posición comprobada en su configurador. También permite uso comercial en sitios, sin registro, mediante iframe y con pronóstico que se actualiza automáticamente; se debe conservar el `src` generado y el enlace a meteoblue. Es menos flexible visualmente porque su contenido queda dentro del iframe. [Widget y condiciones específicas](https://content.meteoblue.com/en/business-solutions/plug-and-play-visuals); [configurador diario](https://www.meteoblue.com/en/weather/widget/setupday/).

Un componente hecho a medida con **Open-Meteo** ofrece el mayor control visual, pero no es la ruta mínima para una emisora que podría tener publicidad o patrocinio: el API gratuito solo permite uso no comercial. El plan de pago sí autoriza uso comercial, requiere clave y endpoint de cliente, y exige atribución de datos CC BY 4.0. La página oficial detalla volúmenes (Standard 1 millón de llamadas/mes) pero no muestra una cifra pública de precio en el HTML consultable: verificarla en su proceso de contratación. En GitHub Pages no se debe poner una clave comercial en JavaScript público; haría falta un pequeño proceso de actualización del JSON mediante GitHub Actions u otro servicio del lado servidor. [Términos](https://open-meteo.com/en/terms); [precios](https://open-meteo.com/en/pricing); [API](https://open-meteo.com/en/docs).

## Geografía: evitar un pronóstico del lugar equivocado

- **La Pacha**: el IGAC la registra como centro poblado de San Sebastián de Buenavista (Magdalena). La Registraduría ubica su **plaza principal/puesto de votación** en `9.257926714465226, -74.25993388252543`. Este punto es una referencia del poblado, no una estación meteorológica. [IGAC](https://mapas2.igac.gov.co/server4/rest/services/carto/carto2000lapacha47692003/MapServer); [Registraduría, listado de puestos](https://www.registraduria.gov.co/IMG/pdf/20230802_puestos-de-votacion-georreferenciacion_territoriales.pdf).
- **La Rinconada**: la Agencia Nacional de Tierras llama así a una **zona** de San Sebastián de Buenavista que comprende siete corregimientos, entre ellos La Pacha y Las Margaritas; CORPAMAG sitúa la ciénaga La Rinconada en Las Margaritas. Sin embargo, la Registraduría también lista Pedregoza (La Rinconada) en **Guamal**, con otro punto (`9.20554926668761, -74.23400690006743`). El nombre solo no permite elegir el pronóstico correcto. [ANT, plan territorial](https://geoportal.ant.gov.co/visor_otr_pospr/47692/47692_POSPR.pdf); [CORPAMAG](https://www.corpamag.gov.co/index.php?catid=11&id=357%3Aliberacion-hicoteas-dia-medio-ambiente&view=article); [Registraduría](https://www.registraduria.gov.co/IMG/pdf/20230802_puestos-de-votacion-georreferenciacion_territoriales.pdf).
- **Ciénaga**: si se trata de la **ciudad/municipio Ciénaga, Magdalena**, MinVivienda publica el punto `11.0057497, -74.2426452`. Está lejos de La Pacha. Si «ciénaga» significa la ciénaga La Rinconada, ese punto de ciudad sería incorrecto; confirmar qué lugar debe llevar esa tarjeta. [MinVivienda](https://www.minvivienda.gov.co/node/39316); [CORPAMAG](https://www.corpamag.gov.co/index.php?catid=11&id=357%3Aliberacion-hicoteas-dia-medio-ambiente&view=article).

## Decisión práctica

1. Confirmar qué significan «Ciénaga» y «La Rinconada» para la audiencia; elegir un punto representativo por cada rótulo. No fingir precisión meteorológica a escala de caserío: los modelos tienen celdas kilométricas.
2. En la primera maqueta, probar los tres puntos en el configurador de WeatherWidget.io y usar sus fragmentos generados sin cambiar enlaces ni código funcional. Si el buscador no devuelve un lugar correcto, usar el configurador de meteoblue para ese punto o aplazar solo esa tarjeta mientras se valida.
3. Rotularlo como **«pronóstico»** o **«clima estimado»**, con fuente visible. «Tiempo real» sugiere medición local instantánea que ninguna de estas opciones garantiza.

Nota: no fue posible inspeccionar de forma fiable el fragmento meteorológico de la web actual; esta comparación toma WeatherWidget.io como proveedor actual según el contexto de la tarea y debe verificarse al migrar.
